
# FIFA 22 Player Performance Analysis | Power BI

An interactive Power BI project exploring FIFA player attributes and comparing player performance across countries, clubs, and playing positions.

## Project Overview

This project focuses on analysing FIFA player statistics and presenting player-performance comparisons through an interactive Power BI report.

The report provides an overview of player metrics and allows exploration of performance across different categories, including nationality, club, and playing position.

## Report Pages

The Power BI report contains nine pages:

| Page | Analysis |
|---|---|
| 1 | Project Cover |
| 2 | Objective, Problem Statement and Tools |
| 3 | FIFA 22 Overview |
| 4 | Overall Analysis |
| 5 | Analysis by Country |
| 6 | Analysis by Club |
| 7 | Striker / Forward Analysis |
| 8 | Midfielder Analysis |
| 9 | Defender and Goalkeeper Analysis |

## Key Analysis Areas

- Overall player-performance overview.
- Comparisons across player nationalities.
- Club-level player comparisons.
- Position-based performance analysis.
- Analysis of attacking, midfield and defensive players.
- Exploration of player ratings and attributes.

## Tools and Technologies

- Microsoft Power BI Desktop
- Power Query
- Power BI data modelling
- Interactive charts, tables, KPI cards and filters

The introductory page of the report also lists Excel, Python and SQL among the project tools. However, separate source files for these tools are not currently available in this repository.

## Report File

**FIFA22_Player_Performance_Analysis.pbix**

The PBIX file is the primary project deliverable. It contains the report pages and Power BI model.

## How to View the Report

1. Download the `.pbix` file from this repository.
2. Open Microsoft Power BI Desktop.
3. Load the downloaded report.
4. Navigate through the nine report pages.
5. Explore the available visuals and filters.

## Project Limitations and Notes

- The original external source dataset and separate Excel, Python and SQL files are not currently available.
- The report title identifies FIFA 22, while the introductory objective and problem statement refer to FIFA 19. This version inconsistency should be corrected in the Power BI report.
- Some page headings need spelling and formatting improvements.
